# Let It Out

[钢炼神插入ED](https://www.bilibili.com/video/BV14x411S7WC/)，每次动画插入这首歌的时候，都特别想哭，钢炼是真的好看啊，不必逞强，脆弱也是力量

爱德华：“人没有牺牲就什么都得不到，为了得到什么东西，就需要付出同等的代价......这就是炼金术“等价交换”的原理...那时我们坚信那就是世界的真实，但是事实上世界并不完善，没有一种原则可以解释一切，包括等价交换原则本身，但是我们仍然相信：没有付出就不会有得到，我们所受的痛苦，一定会成为得到什么的代价，还有…人们通过付出了努力，就一定能够得到什么，等价交换并不是世界的原则 。”
